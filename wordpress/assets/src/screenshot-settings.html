Nemesis Shield Observe

Positive-security runtime protection. Traffic builds a per-site baseline in observe mode; approve behaviours in the Shield console, then flip the app to enforce and off-baseline requests are blocked with 403 blocked_by_nemesis_shield. No redeploy. The mode is pulled live.

Install token

From Protect an app. Prefer setting NEMESIS_SHIELD_TOKEN in wp-config.php to keep it out of the database.
Protect wp-admin

Off by default so a still-learning baseline can never lock you out of your own dashboard. Login and cron are never blocked.
Endpoint (advanced)

Leave blank for Nemesis Shield cloud. Set only for a self-hosted / on-prem Shield.
